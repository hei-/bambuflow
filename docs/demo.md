# 演示手册

用样例数据在一台机器上演示 bambuflow：带引用的问答、按权限得到不同结果，以及数据源同步、索引版本、评测门禁、
紧急拒绝与审计等管理操作。全部在浏览器里的管理控制台（console）完成。

## 1. 准备

- 一台 8 核 32 GB 的机器，装好 Docker（含 compose 插件）、git 与 make。
- **浏览器所在的机器**在 hosts 里加一行（令牌的签发方是 `http://keycloak:8080`，浏览器要能按这个名字打开登录页）：

  ```
  127.0.0.1 keycloak
  ```

- 本机 Docker：复制 `.env.local.example` 为 `.env.local`，加一行 `BF_KC_PORT=8080`，让登录服务占用本机 8080 端口。
- 远端 Docker（`.env.local` 里设了 `DOCKER_CONTEXT`）：不用改端口，环境起来后在本机另开一个终端运行 `make tunnel`，
  它把远端的 console（27300）与登录服务（转到本机 8080）等端口转到本机。
- 回答默认由模拟 LLM 生成：它从证据里直接摘句，结果确定、每句都有依据，但读起来是原文摘录。要看真实模型的效果，
  在 `.env.local` 里填 `BF_LLM_URL`、`BF_LLM_MODEL`、`BF_LLM_API_KEY`（OpenAI 兼容端点），再起环境。

## 2. 启动

```
make demo
```

依次起全部服务、入库样例数据（Wiki 制度、共享盘里的 PDF 与 Office 文件、日志、数据库表结构）、发布索引并跑一次对账，
首次约 10–15 分钟（要构建镜像）。完成后打开 <http://localhost:27300>。

用完 `make down`；要清掉全部数据重来，`make down VOLUMES=1`。

## 4. 推荐演示路线

### 问答（alice，租户“信贷”）

1. **带引用的回答**：问“个人消费贷款的额度上限是多少？”。回答逐句出现，句末的角标是引用；点角标或“预览原文”，
   右侧打开原文片段并高亮被引用的那段。展开“为什么是这个回答（why）”，能看到索引版本、策略版本、各模型版本和意图。
2. **多轮追问**：问“个人住房贷款的首付比例是多少？”，接着问“二套住房呢？”。第二问沿用同一个会话，能理解“二套住房”指首付比例。
3. **多步检索**：问“新旧两版个人住房贷款管理办法在首付比例上有什么区别？”。why 里能看到多步检索每一轮的子问题和检索结果。
4. **枚举与计数**：问“信贷管理部有哪些制度？”和“制度有多少份？”。
5. **不猜测作答**：问“公司食堂的午餐供应时间是几点？”。知识里没有，回答“证据不足”，而不是编一个时间。
6. **反馈**：在任意回答下点“有用”“有误”或“引用不对”。

### 按权限得到不同结果

1. alice（租户“信贷”）问“单一集团客户授信总额上限是多少？”：这是风险管理部的制度，alice 没有权限，回答证据不足。
2. 退出，换 bob（租户“风险管理”）问同一个问题：给出答案和引用。
3. 同一租户内也一样：alice 和 sam 都切到租户“运维”，问“贷款余额视图有哪些字段？”。sam 能看到数据库表结构并得到回答，
   alice 看不到。

权限在召回之前生效，返回前再复核一次；没有权限的内容不会进入候选，也不会出现在引用里。

### 管理（olga、oscar、paul、pete、dana、ivan、audra）

1. **数据源同步**（olga）：在“数据源”里选“制度 Wiki”，看最近一轮同步、新鲜度和最近一次对账（漏同步、内容或权限不一致、源端已删的计数）。
   演示“暂停”与“恢复”。“立即同步”在 compose 环境里会提示没有接入调度：部署到 Kubernetes 时由 CronJob 拉起。
   **注册与审批**：paul 点“注册数据源”，属主部门填“信贷部”、密级选“受限”；退出换 dana，选中它点“属主审批”（填工单号），
   状态变为“待信息安全审批”；再换 ivan 点“信息安全审批”后生效，dana 即可在“租户授权”里授权给租户。审批都要求刚登录过。
2. **索引版本**（olga 发起、oscar 复核）：olga 对一个已下线的版本点“回滚到此版本”并填写原因，得到一个待复核的操作 ID；
   olga 自己复核会被拒绝；退出换 oscar，在“复核切换”里填入操作 ID，复核后线上版本切换。
   复核属于审批类操作，要求 10 分钟内刚登录过（加强认证）：登录较久或沿用了单点登录会话时，console 会提示“需要重新认证”，
   重新登录后回到本页再提交一次。
   之后可以再由两人把线上版本切回最新的那个。
3. **评测门禁**：每次发布索引前都在待发布版本上跑一次评测，通过才上线。点开一条记录看指标和报告。
4. **紧急拒绝**（olga）：按文档拒绝一份制度（文档 ID 在引用预览里能看到），1 分钟内再问相关问题就不再引用它。
   **注意**：紧急拒绝只能新增、不能撤销，演示环境要恢复只能 `make down VOLUMES=1` 后重新 `make demo`。
5. **审计**（audra）：按用户 alice 查询，能看到她每次问答时的候选、进入上下文和展示给她的内容。查询本身也会被审计。
6. **租户配置**（paul 提交、pete 审批）：paul 在“租户配置”里选“信贷”看版本历史，点“提交变更”改配额并填原因；
   退出换 pete，在“变更单”里找到这张待审批的变更单点“审批通过”（同样要求刚登录过），新版本 1 分钟内推到 gateway，
   “发布”里多一条生效中的发布，可以一人回退。“新建租户”同样生成一张变更单，审批后生效。
   从试点切到全量要附一个评测门禁 ID，样例评测集的题都未复核，会被拒绝（见 docs/onboarding.md）。
7. **评测集**（paul，右上角选租户）：“候选题复核”里通过或驳回候选题；“负反馈案例”里是前一天被标为“有误”“引用不对”的回答，
   每日抽样任务登记后才出现（compose 环境用 `docker compose run evaluation-api online-sample` 手动跑一次）。
8. **运维状态**：olga 看各服务的配置快照是否都已同步；audra 按文档或数据源查删除凭证。
9. **入库运维**（olga）：按文档 ID 查入库状态；“死信与隔离文档”里勾选文档或按数据源、阶段筛选后重放。样例数据正常入库时没有死信。
10. **A/B 实验、受控词表、插件**（paul）：立项一个实验（从 5% 流量开始，展开一行看 A/B 分析，样本量不够时只显示进度）；
    在受控词表里新增或停用词条（停用要指定替代编码）；登记一个 Tool 插件后换 ivan 做信息安全评审。

## 5. 常见问题

- **登录页打不开 / 显示 keycloak 无法访问**：检查 hosts 里的 `127.0.0.1 keycloak`，以及 8080 端口
  （本机 Docker 设了 `BF_KC_PORT=8080`；远端 Docker 在跑 `make tunnel`）。
- **登录后提示“无权执行”**：当前账号没有这个页面需要的角色，见第 3 节的账号表。
- **问答返回“服务暂时不可用”**：环境刚起来时部分服务还在加载，稍等后点“重试”；仍不行时看 `docker compose logs gateway orchestrator`。
- **回答全是原文摘录**：用的是模拟 LLM，见第 1 节。
