# 术语表

选词原则见 `AGENTS.md` 第 8 节。本表记录已经确认的写法：左列不再使用，新增词条时同步更新技术设计文档第 17 节“术语规范”。

| 回填父块 | 父块扩展 | Parent Expansion |

保留不改（业内通行）：召回、精排、半开、扇出、兜底、fail-closed、RAG、chunk、embedding。

已确认可直接使用：受控词表（Controlled Vocabulary）、存在性校验、分桶（评测集按题型分组）、拒绝名单（Deny List）、复制位点（数据库为每次提交分配的单调位置，如 LSN、GTID）、撤权位点（最近一次权限或删除变更的提交位点）、试运行（新逻辑只记录不生效，不说“影子模式”）、合并推出（多个已验证事实合起来能否推出综合句，不说“合取”）、快照、灰度、变更单、生效指针（某配置对象当前生效的版本）、紧急拒绝规则（只能新增、1 分钟内生效的拒绝访问规则）、冒烟集、回放环境、待复核题、评测配置（镜像、配置快照、索引版本、评测集版本、判定器版本这一组输入）、判定器、成对对比、临界重跑、令牌交换（OAuth Token Exchange，RFC 8693；Entra ID 称 OBO）、入口审计、自适应并发、合成题（LLM 生成、经人工审核后入集的评测题）、试点阶段 / 试点群组（新租户问答只对试点群组开放的上线阶段）、平台授权服务（平台自带的登录与令牌服务，代理公司 IdP）、平台身份库（identities 与 identity_groups 两张表）、身份同步（把公司目录的用户属性与群组写入平台身份库）、部署配置清单、分区级 / 文档级数据源（按知识库或目录授权 / 对单份文档授权，ADR-14）、分区授权（partition_grants，分区到部门或群组的授权）。

已弃用：心跳新鲜度、冻结模式（K9 改用复制位点后不再需要，ADR-13）。

流程命名不用“一次 X”的句式，写成“问答请求”“文档入库”“权限撤销”“索引回滚”。
