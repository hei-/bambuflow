# 抵质押物管理规程

## 抵押率上限

| 抵押物类型 | 抵押率上限 |
| --- | --- |
| 住宅 | 70% |
| 商业用房 | 50% |
| 土地使用权 | 40% |
| 存单、国债质押 | 90% |

## 价值评估

抵押物价值由本行准入的外部评估机构评估，评估报告有效期为 12 个月；金额 500 万元以上的须由两家机构分别评估，取较低值。

## 重新评估

住宅抵押物每 2 年重新评估一次；所在区域房价指数一年内下跌超过 10% 的，应在 1 个月内重新评估。

## 权证保管

抵押权证由分行押品管理中心集中保管，出入库须双人经办，调阅须经信贷部负责人审批。
